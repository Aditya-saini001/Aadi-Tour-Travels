# Aadi Tour & Travels

A modern, professional taxi/tour service website for **Aadi Tour & Travels**, Dehradun, Uttarakhand.

Built with **Next.js 14** + **Tailwind CSS** + **TypeScript**.

## 🌐 Live Demo
Deploy on Vercel to get your live link!

## 🚀 Features
- 🏠 Beautiful Home page with Hero + Booking Form
- 📋 Booking Form → WhatsApp redirect with pre-filled message
- 📞 Floating Call Button (always visible)
- 💬 Floating WhatsApp Button (always visible)
- 🏆 Why Choose Us section
- 🚗 Popular Services section
- 👥 Our Team section
- ❓ FAQ Accordion
- 📜 Terms & Conditions page
- 📱 Fully Responsive (Mobile, Tablet, Desktop)
- 🎨 Classical Deep Navy & Gold color scheme

## 🛠️ Tech Stack
- Next.js 14 (App Router)
- Tailwind CSS v3
- TypeScript
- Lucide React (Icons)

## 📦 Getting Started (Local)
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## ▲ Deploy on Vercel
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → Import GitHub repo
3. Click Deploy → Get your live link! 🎉
